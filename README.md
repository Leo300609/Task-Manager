# 📝 Task Master Pro - Gerenciador de Tarefas com Agendamento

Um gerenciador de tarefas moderno e responsivo desenvolvido com foco em **UI/UX** e **Persistência de Dados**. O projeto permite criar, organizar e filtrar tarefas com data e hora marcadas.

## 🚀 Tecnologias Utilizadas
* **HTML5**: Estrutura semântica dos elementos.
* **CSS3**: Estilização avançada com efeito *Glassmorphism* e animações.
* **JavaScript (ES6+)**: Manipulação de DOM, Array de Objetos e lógica de filtros.
* **LocalStorage**: Persistência de dados para evitar perda de informações ao recarregar a página.

## 🛠️ Funcionalidades
- **CRUD Completo**: Adição, leitura e exclusão de tarefas.
- **Agendamento**: Input de data e hora formatados para o padrão brasileiro (`pt-BR`).
- **Filtros Dinâmicos**: Visualização por Todas, Pendentes ou Concluídas.
- **Responsividade**: Interface adaptável para diferentes tamanhos de tela.

## 🎨 Layout
O design utiliza o conceito de **Glassmorphism**, garantindo uma estética moderna e limpa, ideal para portfólios de Desenvolvimento de Sistemas.
